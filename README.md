## 📜 Sobre

Código da época em que eu ainda estava aprendendo a programar — e a fazer segurança.
Não, não tá seguro. Nunca foi.

PHP misturado com HTML do jeito que se fazia naquela época: sem framework, sem frescura, sem arrependimento (talvez um pouco).

### Stack do museu

| Tecnologia | Motivo |
|---|---|
| **ASP.NET WebForms (C#)** | GridView, SqlDataSource, DataList, Session — a beleza dos anos 2010 |
| **PHP** | Aparentemente eu não sabia escolher uma stack só |
| **HTML** | Direto no meio do código, do jeito que o pai ensinou |
| **Access (.mdb)** | Sim. Banco de dados Access. OLEDB. Sim. |
| **Smalltalk** | Aparecia no gráfico do GitHub sem motivo. Ninguém sabe de onde veio. Provavelmente o GitHub viajou. |
| Visual Studio 2008 | Porque era o que o professor mandou. Sem questionamentos. |

## ⚠️ Aviso

Este repositório **não** deve ser usado como referência de boas práticas, exemplo de arquitetura, padrão de segurança ou stack recomendada em 2024+.

Deve ser usado como museu, registro histórico, piada interna e prova de que todo mundo começa de algum lugar.
